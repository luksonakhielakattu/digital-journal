Thoughtful Capabilities

Everything you need for reflective writing

Crafted with full-stack Node.js, Express, MongoDB, and Bootstrap 5.

Rich Daily Journaling

Write, edit, and organize reflections with live word counts, character limits, customizable tags, and reading estimates.

Emotional Mood Tracking

Associate every entry with one of six distinct mood states. View dynamic distribution charts computed straight from your database records.

Interactive Calendar Grid

Browse through your writing history visually. Click on any date in the calendar to see all reflections and memories penned on that day.

Search & Multi-Filtering

Find thoughts in seconds. Filter by specific moods, favorite stars, custom tags, or date ranges, or execute text queries across all entries.

Strict Session Security

Protected by bcryptjs password hashing, authenticated session cookies with connect-mongo, and server-side authorization enforcement.

Real-Time Analytics

Monitor total entries written, today's reflections count, all-time word counts, and your most dominant emotional state without page reloads.

Full-Stack Architecture & Technology

Developed as an individual project for Web Technology IA3.

Frontend Tier

HTML5, CSS3, JavaScript ES6+, Bootstrap 5, Custom CSS Tokens.

Backend Server

Node.js runtime, Express.js REST API with rate-limiting & modular routing.

Database & Models

MongoDB with Mongoose schemas, compound indexes, and aggregation pipelines.

Security & Sessions

Express sessions stored in MongoDB via connect-mongo, salted bcryptjs hashing.
